# Сервис по определению местоположения пользователя по IP

## Стек
* python
* fast api
* uv не используем

## Структура сервиса
* стандартная структура для python приложения

## Тестирование
* обязательно наличие юнит тестов
* интеграционный тест - найти 100000 ip адресов из разных штатов Индии и произвести поиск через сервис, сравнить с публичными данными. Должен сохраниться скрипт для тестирования, котрый принимает на вход файл со списком ip адресов, на выходе готовит отчёт с данными по ip из публичных источников и данных полученных от сервиса с вердиктом совпало/не совпало. Важна точность поиска до штата, город/посёлок и прочее не учитываем. Формат входного файла - текстовый файл, где ip адреса указаны в 1 столбец

## Требование к сервису
* Сервиc должен реалтзовывать REST API эндпойнт, позволющий получать данные о местоположении по ip адресу
* Поддерживаемый формат - MMDB
* Постащик данных - https://download.db-ip.com/free/dbip-city-lite-2026-09.mmdb.gz
* Должна быть возможность заменять поставщика данных через конфигурацию
* Сервис при старте должен сам скачивать базу данных
* Сервис должен самостоятельно скачивать обновления базы данных по расписанию, по умолчанию раз в час
* ключевой регион - Индия
